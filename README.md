# ResolveAI

ResolveAI is a multi-tenant Agentic AI Customer Support SaaS Platform for e-commerce businesses.

It allows multiple companies to manage customers, orders, payments, refunds, tickets, policies, support agents, dashboards, and AI-powered ticket resolution inside isolated workspaces.

The platform uses multi-agent orchestration, RAG, business data lookup, risk scoring, SLA management, human approval, explainable AI, root cause analysis, supervisor copilot, and feedback learning.
